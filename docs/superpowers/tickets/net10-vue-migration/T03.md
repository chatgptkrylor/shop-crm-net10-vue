## Acceptance criteria

- `GET /api/dashboard` (authed) returns `200 { totalCustomers, statusCounts: [{ status, count }], recentInteractions: [Interaction], username }`.
- `CustomerRepository` and `InteractionRepository` are registered as Scoped and use async ADO.NET (`Microsoft.Data.SqlClient`) with SQL text ported verbatim from the old repos; `MapCustomer`/`MapInteraction` helpers ported unchanged.
- `DashboardController` is `[Authorize]` and resolves the username from the JWT claim.
- The Vue `DashboardView` renders stat cards for `totalCustomers` and `statusCounts`, and a list of `recentInteractions`; `onMounted` calls `dashboardStore.fetch()`.
- `dashboardStore` exposes `data` and `fetch()`; `dashboard.ts` Axios module calls `GET /api/dashboard`.
- `DashboardTests` xUnit passes (authed 200 with expected shape; unauthed 401). `smoke-content.sh` dashboard assertions pass. Playwright `dashboard.spec.ts` screenshots the rendered dashboard and verifies `totalCustomers` and recent interactions are visible with a clean console.
