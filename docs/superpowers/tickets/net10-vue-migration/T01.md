## Acceptance criteria

- .NET 10 (preview) SDK is installed and `dotnet --version` reports a 10.x build.
- SQL Server 2022 Developer is running on `localhost:1433` with SQL auth; the SA password is stored in .NET user-secrets (`DbPassword`) for the `ShopApi` project.
- `dotnet dev-certs https --trust` has been run.
- `schema.sql` has been run against the new instance, creating `ShopCRM` with the seeded admin user, 10 customers, and 5 interactions.
- `src/backend-net10/ShopApi.sln` exists containing `ShopApi` (webapi) and `ShopApi.Tests` (xunit) projects.
- `ShopApi/Program.cs` registers DI, maps `GET /health` returning `200 { "status": "healthy" }`, and configures `MapFallbackToFile("index.html")`.
- `src/frontend-vue/` is a Vue 3 + TS + Vite + Pinia + Vue Router + Element Plus project; `vite.config.ts` proxies `/api` to `http://localhost:5000` and sets `build.outDir` to `../backend-net10/ShopApi/wwwroot`.
- `tests/smoke-health.sh` curls `/health` and exits 0 on a 200 response.
