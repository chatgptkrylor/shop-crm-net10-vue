## Acceptance criteria

- `GET /api/customers/{id}/interactions` returns `200 [InteractionDto]`.
- `POST /api/interactions` with `{ customerId, type, note }` returns `201 InteractionDto`; `LoggedByUserId` and `LoggedByUsername` are set from the JWT claims (not from a SQL join). Invalid body returns `400 ValidationProblemDetails`.
- `InteractionDto` validation mirrors the old `InteractionViewModel` (Required Type, Required non-empty Note).
- `InteractionsController` is `[Authorize]`.
- The Vue `CustomerDetailsView` renders the customer fields and the embedded interactions list (`el-table`); a "Log interaction" button opens an `el-dialog` with an Element Plus form (Type select, Note textarea) that calls `interactionsStore.create()` and refreshes the list on success.
- `interactionsStore` exposes `byCustomer, fetchByCustomer, create`; `interactions.ts` Axios module calls the endpoints.
- `InteractionsTests` xUnit passes (create with `LoggedByUsername` from JWT, list by customer). `smoke-crud.sh` interaction assertions pass. Playwright `interactions.spec.ts` screenshots the details page and logs an interaction (it appears in the list).
